# 📚 Online Book Store

## About the Project
The Online Book Store is a web-based application developed using HTML, CSS, JavaScript, PHP, and MySQL. It provides a platform for users to browse books and access book information. The system includes user and admin modules to simplify book management.

## 🚀 Features

### User Module
- User Registration
- User Login and Authentication
- Browse Available Books
- View Book Details
- Manage User Profile
- Add Books to Wishlist

### Admin Module
- Admin Login
- Add and Manage Books
- Manage Authors
- Manage Categories
- Manage Book Information

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP

⚙️ Installation and Setup

1. Install XAMPP on your computer.
2. Download or clone this repository.
3. Copy the project folder into the `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin and create or import the required database.
6. Update the database connection settings in the PHP configuration file.
7. Open your browser and visit `http://localhost/online-book-store/`.

🎯 Project Objective
The main objective of this project is to develop a user-friendly online platform for browsing books and managing book-related information efficiently.
